# 故事神谕（Story Oracle）—— SillyTavern 扩展

一个可拖动的侧边面板：连接你自定义的 **OpenAI 兼容** 端点，针对*正在进行中*的剧情向 LLM 提问。
问答在它**独立的窗口、独立的历史**里进行——**完全不碰你的主聊天**，随时可清空。

**它能帮你做六件事**（顶部图标切换，互斥）：

- 💬 **普通聊天** —— 问剧情：「她为什么这么做」「现在好感度多少」。
- 🩺 **诊断** —— 修 MVU 状态变量（数值 / 状态栏对不上时）。
- 📖 **世界书** —— 聊世界书，或让它**直接帮你改**世界书。
- 🧭 **剧情参谋** —— 一起构思剧情走向，并可**悄悄引导**主聊天（含多拍长线「弧线」）。
- ✨ **校正** —— 一键修掉最新回复的「AI 味」（手动指定，或自动每条）。
- 🎭 **角色工坊** —— 聊几句就把一个角色从零打磨成完整设定，写进你的人设或世界书 NPC 条目。

> **v1.52.0 新增（📖 世界书 EJS 模板渲染，opt-in）**：如果你的世界书条目里写了「提示词模板」（ST-Prompt-Template）扩展的 `<% %>` 模板（比如按好感度切换人设的动态条目），神谕以前读到的是**模板原文**——那些模板只在主聊天生成时才执行，所以神谕"看得到但看不懂"。现在在「设置 → 世界书 / 知识库」下勾选「**支持读取 EJS 世界书条目**」，神谕在**普通问答 / 剧情参谋 / 手动校正**读世界书时就会先把模板跑一遍，看到**与主聊天完全一致的成品文本**（变量值、条件分支都是真的），顺带还更省 token。需已安装「提示词模板」扩展；没装时勾了也会自动按原样读取、零副作用。⚠ 一点须知：含「**写**变量」（setvar 等）的条目会因此被**额外执行**、可能影响卡内变量——遇到异常关掉本项即可（默认就是关的）。诊断 / 世界书编辑 / 角色工坊 / 弧线 / 插件接口**有意不执行**模板（各有各按原文处理的理由，比如编辑模式改的就是模板原文本身）。

> **v1.43.1 修复（🎭 工坊：聊天里改出来的整稿会凭空消失）**：在工坊里让访谈师**整篇重写**一份角色稿时（比如「不要小修小补，给我一版重置的」），它给出的是一整份草稿而不是逐句小改——而神谕以前**接不住**这种草稿：稿子只印在聊天里，顶部的常驻卡纹丝不动，一直停在「已有访谈汇总（草稿还未生成）」，而且**一声不吭**（用户书亦报告）。现在这种整稿会**照常收进常驻卡**（自动展开工坊面板，跟点「🔨 生成」出稿一样，可以接着改、接着「写入」）；若它写的草稿格式不全（比如漏了机器读的头部行），也会**明说没收下、给出原因**，不再静默丢掉——你原来那份草稿也不会被这种半成品冲掉。

> **v1.43.0 新增**：诊断 🩺 也能「套用我的补全预设」了。诊断设置里新增一个复选框，勾上后诊断指令会叠加在你策展好的补全预设之上（**手动诊断与自动诊断都生效**）——和世界书 / 参谋 / 工坊 / 校正一样，主要给模型拒绝做变量审计时破限用（诊断读的是主聊天正文，内容敏感时带审查的模型照样会拒绝）。若你在预设下拉里选的是**内置破限**，它同样跟着这个复选框走。默认关；预设的额外内容会分散模型注意力、影响诊断精度，不需要就别开。

> **v1.42.0 新增**：主聊天快捷入口——最新一条 AI 回复的消息按钮行会出现一个 ✂️ 按钮——在正文里划选一段文字后点它（装了「右键消息菜单」类扩展的话，右键菜单里也会自动出现「选段校正」），神谕会自动打开窗口、切到校正模式，并把你划选的那段在选段卡里预先选好、滚到眼前。没划选直接点也行＝一键打开选段卡。若正文被翻译类扩展改写、或选的是状态栏里的字，定位不到原文时卡会照常打开并提示你在卡内重新划选（绝不会错选乱改）。若当时有回复正在生成，会先弹「仍要切换吗」确认——点取消则一切原样不动。

> **v1.41.0 新增（🩺 把诊断修正写进正文 —— 实验性，默认关）**：自动诊断的修正一直只写进 MVU 的**实时状态**、不动消息正文。于是只要点一下 MVU 的**「重新处理变量」**（它会把那一楼的变量清空、只照消息正文重新算一遍），这次诊断的修正就**没了**——用户 smallmj 报告：他要靠这个按钮让智绘姬的插图加载出来，于是陷入「重新处理→修正丢→重新应用→插图又卡住」的死循环。**设置 → 界面**里新增「**把诊断修正写进正文（实验性）**」（默认关；放在折叠的「界面」组里，用不到的人不会撞见它）：勾上后，修正会作为一小段补丁写进这条回复**已有的那个更新区块内部**（不是另起一块——那会让多数卡片的状态栏被折叠面板吞掉），于是无论点多少次「重新处理变量」，算出来的都是修正后的结果。写进去的是**实际算出来的结果值**而不是「加多少减多少」，所以重算多少次都落在同一个数上。**注意**：目前只作用于**自动**诊断——手动「🩺 诊断」点「应用」仍然只写实时状态；**非必要请保持关闭**。**顺带修好**：以前点「撤销此次修复」只还原变量、却把写进正文的那段留着，下次「重新处理变量」又会照着它算回来 = 撤销等于白撤（推导补块那条路一直如此）；现在撤销 / 重新应用都会**连正文一起**同步。

> **v1.40.2 修复（🩺 自动诊断把同一笔变化算两次）**：如果你的卡片用的**不是** MVU 那套标准 `<UpdateVariable>` 标签，而是自己的写法（比如 `<update>` ＋ `<json_patch>`），神谕以前**认不出**它——于是每回合都误判成「这条回复还没更新过变量」，自己照剧情**又推导了一遍**，跟主模型那份叠在一起：**花掉的钱扣两次、好感度加两次**（用户 smallmj 报告）。现在更新区块的识别**不再写死一种标签**，卡片自定义的写法也认得；并且判断改成**宁可只核验、不轻易推导**——只要看出这条回复里**有**更新（哪怕格式不标准、我们摘不干净），就一律只做核验，绝不重算一遍。真的一个更新块都没有时，才照旧推导补上（「替代 MVU 额外模型解析」这个用法不受影响）。**顺带修好的两处**：① 这类卡片的更新块以前会**漏剥**，原样混进普通聊天 / 剧情参谋的上下文里（增量数字会误导模型瞎报数值）；② 开了**自动校正**时，换成校正稿的那一版**会把卡片的更新块弄丢**。另外，自动诊断发出去的提示词现在也能在「**调试提示词**」面板里看到了。
>
> **v1.37.0 新增（✂️ 选段校正 · 多段钉选——一次改好几段）**：选段校正现在能**一次钉住好几段**分开改。在弹出的全文里划选一段、点 **📌 钉住这段**（最多 8 段），每段下面各写一句「这段怎么改」——**留空就用上面的整体要求**；钉好的段在原文里标**冷蓝色**、正在划选的那段仍是琥珀色。段数会**如实报价**：没钉或只钉一段还是老样子「开始校正」，钉了 2 段起按钮变成「开始多段校正（N 段，N 次调用）」。点下去后**每段各发一次调用**（最多 3 路并行、其余排队），改完给一张**逐段清单**——每段各有 **[看改动]** diff、各自打勾决定采不采用，标题如实写「改了 X 段 / 保留 Y 段 / 失败 Z 段」，失败的段还有 **[重试失败的 Z 段]** 一键重发（沿用原来那次的请求，不重新抓上下文）。确认后**代码按字符偏移把各段一次性精确回插**（从后往前拼、段落之间绝不错位），原回复照旧留在左滑、不破坏存档。**你没钉住的文字一个字都不进模型**，从机制上就不可能被改动。**只钉一段（或不钉、直接划选一段）时，行为和旧版选段校正完全一致。**
>
> **v1.36.0 新增（⏳ 生成中切模式先确认 + ✂️✂️ 深度精简后台保活）**：两件事，都是治「切模式把正在生成的回复切没了」。① **切换模式的中断确认**——以前有回复正在生成时点别的模式按钮，这条回复会被**直接中止丢弃**（各模式侧聊房间独立、在途回复切走即作废——这是设计行为，但容易误当 bug）。现在会先弹一个确认框「当前还有回复正在生成——现在切换会中止它，未完成的内容将丢弃」，确定才切、取消留在原地。② **深度精简享受锻造同款后台保活**——「✂️✂️ 深度精简」是和锻造一样的多分钟重调用，以前切个模式就把它中止、白花钱；现在切走后它在后台照常跑，回到工坊时流式气泡自动接上，完成后成稿按原始房间落盘归位（所以它也不会触发上面的确认框）。两点不变：生成期间发送键是 ⏹ 停止键（点它仍会中止后台调用）；**切换聊天**仍会中止一切在途调用（结果属于旧聊天，不会写进新聊天）。

> **v1.34.1 修复（✨ 思维链兜底加强 · 只剩 `</think>` 的思考也剥得掉）**：有些预设会把 `<think>` 开标签**预填在发给模型的消息里**（有些推理模型也会省略开标签），于是模型回复里**只剩一个 `</think>` 闭标签**、前面一整段思考被当正文直接吐出来——神谕以前遇到这种「只有闭标签」的情况只删掉标签字面量、把整段思考**漏在气泡里**（普通聊天 / 剧情参谋尤其常见，思考还会被当上下文喂回下一轮）。现在**闭标签出现在开标签之前时，从开头到 `</think>` 的整段思考会连内容一起剥掉**（气泡显示与侧聊历史两头都剥）。护栏：已知结构区块（`<StoryPlan>` / 校正稿 / 角色草稿 等）若排在闭标签之前，则一律不动——绝不会误删你的方案或草稿。
>
> **v1.34.0 新增（🎭 角色工坊 · 台词丰满）**：不少朋友反映锻造出来的角色卡里**台词偏干**——意思对、性格对，但一句句短得像电报，用起来总要再手动让模型「把台词写得更丰满自然些」。现在工坊设置里多了一个开关「**台词丰满（锻造台词写成完整人话）**」（默认关）：勾上后，锻造稿里所有台词（说话方式的示范句、多副面孔的各面语料、画面里的对白）都会写成**当面说出口的完整人话**——带着角色当下的口气和说话习惯、容得下情绪和细节；**话少的角色照旧话少**，但开口的那几句会把事情一口气说完整，而不是拆成几个词往外蹦。角色个性、条数与卡片结构完全不变。这一段追加指令在 DeepSeek / Gemini / Claude 上都做过对照验证（包括「寡言角色会不会被写成话痨」「泼辣与沉默角色的嘴会不会混」这类专项裁判）——嫌台词干就开它，喜欢极简电报腔就保持关闭。

把整个 `story-oracle/` 文件夹放进 SillyTavern 的第三方扩展目录，刷新浏览器：

- **较新版 ST**：`SillyTavern/data/<用户名>/extensions/story-oracle/`（默认 `default-user`）

### 🔔 更新提醒（1.38 起）

打开神谕窗口时会**自动检查一次新版本**（每次刷新页面后的首开各查一次）：发现 GitHub 上有更新，标题栏的 **⋯ / ⚙ 按钮**和设置面板顶部的**「更新」组**会亮**红点**，组里显示「发现新版本 vX.Y.Z」和一个**「立即更新」**按钮——点它走酒馆自带的扩展更新机制拉取新版，成功后 **5 秒自动刷新页面**生效（**点一下提示可取消刷新**，稍后自己刷新也行）。

- **一键更新的前提**：扩展是通过酒馆「下载扩展」（填 GitHub 地址）安装的。手动复制文件夹安装的话一键更新会失败，按提示到「扩展管理」里更新、或到 GitHub 重新下载覆盖即可。
- **隐私**：检查只是读取 GitHub 上的**公开版本号文件**（打不开时换 jsDelivr 镜像再试一次），**不发送任何数据**；失败就静默跳过，不打扰。
- 不想要的话，「更新」组里**取消勾选「自动检查更新」**即可（之后不再有任何联网检查）。

## 设置

标题栏「⋯ 更多」菜单 → ⚙ **设置**。两种连接方式：

- **直连（Direct，默认）**：填端点 URL（如 `https://your-proxy.com/v1`，会自动补 `/chat/completions`）、API 密钥、模型。密钥明文存在 ST 的 settings.json（个人 / 自建实例无妨）。
  - **经酒馆后端转发（避免跨域 CORS）** ✅：直连报 **CORS / failed to fetch** 时勾选此项——**用的还是上面这个端点和密钥**，只是改由酒馆服务器代发，绕开浏览器跨域，**无需连接配置文件**。勾选后**「获取模型」也经酒馆服务器代发**（1.18.1 起），拉模型列表不再撞跨域。
  - **地址原样使用（不自动补 /v1）**（1.22 起）：给路径特殊的中转站用——地址明明填对了却 404 / 拉不到模型，多半是被自动补了 `/v1`。勾选后按你填的地址原样请求（补全只剩 `/chat/completions`，「获取模型」同理打到 `地址/models`），常与上面的转发开关配合使用。
  - **连接存档**（1.20 起，1.40 更名）：直连区底部可把当前的**端点 / 密钥 / 模型（1.22 起含「地址原样」开关）**存成命名存档，随时用「保存 / 加载 / 删除」一键切换不同服务商；删除前会弹确认框。⚠ 这里的「存档」与下面「系统提示词」区的**补全预设**是两回事——1.40 前它叫「连接预设」，有用户因此误以为那是自定义预设区，故更名。
- **连接配置文件（Profile）**：选一个你保存好的 ST 连接配置；请求走 ST 后端转发，**不会被 CORS 拦**。⚠ 注意：若该配置文件**没有自带独立密钥**，ST 会回退用你**当前激活连接**的密钥——此时神谕选的配置文件必须与酒馆当前正在用的连接一致，否则会 **401 / 400**（密钥被发给了不认它的端点）。想彻底避开这个坑，多数情况下直接用上面的「直连 + 经酒馆后端转发」更省事。

常用选项：温度、最大 token、**上下文深度**（喂多少条最近消息，`-1` = 整段、`0` = 不喂）、是否带角色卡、系统提示词。普通模式还会**默认带实时变量状态**（stat_data），所以「好感度多少」会按真实数值回答；关掉或卡无 MVU 时它会**如实说看不到数值**而不瞎编。世界信息来源可选「全部激活的世界书」「**仅角色相关（排除全局）**」等，并可开「**读取隐藏楼层**」让它读到 `/hide` 的楼层。设置项按用途分组、可折叠，默认只展开「连接」。

## 🔓 内置破限（1.40 起）

模型动不动就拒绝、说教、或者把该写的地方一笔带过？设置里的**「补全预设」**下拉现在自带一项：

> **🔓 内置破限 · 初心破限1.0（出自 初遇大佬）**

选它就生效。**新装用户、以及从没选过预设的用户，默认已经帮你选好了**；如果你**已经选好并挑选过
自己的预设**，我们**不会动你的选择**。

**它是「包一层」，不是「换掉」。** 普通预设那条路是**整体替换**掉神谕自己的提示词；内置破限不一样，
它把破限块包在神谕自己的提示词**外面**——神谕的分析框架、戏外守卫、各模式的结构化格式全都照常在用。
所以下方的系统提示词文本框**不会被停用**。

**默认只作用于【普通聊天】。** 其它模式要不要跟着用，由你自己决定——去各模式的设置里勾上
**「经自定义补全预设」**即可（世界书 / 剧情参谋 / 角色工坊访谈 / 校正手动 / 校正自动）。
**🩺 诊断模式永远不接**：它只做机械的变量修复，没有「拒绝」这回事，而它的解析器最敏感。

**随时可以取消**：在同一个下拉里换回「— 自定义 —」或你自己的预设就行。

开了之后，剧情参谋会明显更爱主动说「我可以帮你把这段写出来」。

## 💬 普通聊天

默认模式，问剧情即可。系统提示词每次发送时重建，所以神谕看到的永远是最新故事状态。

## 🩺 诊断模式（Diagnose）

修复 MVU（MagVarUpdate）的状态变量。神谕读取本卡的 MVU 规则、当前 `stat_data`、以及最新回复里的 `<UpdateVariable>`，对照剧情给出一份**保守的纠正补丁**；气泡下方出现 **将修复应用到状态** 按钮，通过 MVU 自己的管线应用，并可一键**撤销**。全量审计输出较长，token 上限已自动抬到 ≥4096。

**自动诊断（AUTO）⚠ 实验性。** 诊断按钮三态循环：关 → 🩺 **诊断**（手动）→ 🩺 **AUTO**（红色）。切到红色后，主聊天每来一条新回复都会在后台自动诊断并**自动应用**——回复里**有**变量更新区块就只做核验（卡片用自定义标签如 `<update>` 也认得，v1.40.2 起），**完全没有**才据剧情推导补上（可替代 MVU「额外模型解析」，但勿与之并用）。每轮在侧聊留一条记录（有改动的带「撤销」），并把更新写回消息、刷新状态栏。

> ⚠ 这是**唯一会自动写入 MVU 状态**的功能，故**默认关、需手动切到红色**，首次开启有提醒。拿不准就停在手动「🩺 诊断」——它只在你点了之后才出补丁。

**把修正写进正文（可选，实验性，默认关）。** 默认情况下，诊断的修正只写进 MVU 的**实时状态**、不改动消息正文——于是一旦点了 MVU 的**「重新处理变量」**（它会把那一楼的变量清空、只照正文重新算一遍），修正就没了。在**设置 → 界面**里勾上「**把诊断修正写进正文（实验性）**」后，**自动**诊断的修正会作为一小段补丁写进这条回复**已有的更新区块内部**，重新处理变量时照样算得出同样的结果；撤销时那段也会一并撤掉。写进去的是**结果值**（绝对值）而非增减量，所以反复重算不会漂。**目前不覆盖手动诊断**——手动「🩺 诊断」点「应用」仍只写实时状态。非必要请保持关闭。

**精选条目（可选）。** 勾「用精选条目」后可像世界书模式那样**逐条挑**要喂给诊断的条目，且**无视** ST 的启用 / 禁用状态——于是被禁用（以保持主聊天干净）的变量规则条目也能单独喂给诊断。带快捷选择与筛选，**按当前聊天记忆**。

## 📖 世界书模式（Lorebook）

**聊**世界书（里面写了什么、设定在哪条、有无矛盾、怎么扩写），或让它**直接改**世界书。进入后标题下方有一条工具栏：

- **选书**：默认「当前激活的全部世界书」，也可**勾选某一本或几本**（支持多选）。
- **条目选择器**：默认发整本，可展开后用复选框只挑几条发给神谕（带筛选 + 全选 / 仅蓝灯 / 仅绿灯 等快捷键，**👁 内容预览** 可每条显示一行摘要）。只影响发给 AI 的内容，应用时仍读整本，编辑任何条目都照常生效。**（1.40.1 起）你的勾选会按书名记住、刷新与重开都还在**，不用每次重勾；把某本书**整本勾满**会自动回到「发整本」状态——这样以后往这本书里新增的条目会自动被包含，而不是被旧勾选挡在外面。想只发整本，点「全选」即可。

要求改动时，神谕会用中文说明改了什么，并附 `<LorebookEdit>` 区块（**分隔格式**而非 JSON，长正文放进 `<<<content … content>>>` 围栏里原样书写、无需转义）。四种操作：`create` 新建、`edit` 整条覆盖、`patch`（默认——「开头几字 || 结尾几字」锚定只换一段）、`delete`。随后出现 **将改动应用到世界书** 按钮：通过 ST 的 `saveWorldInfo` 写回、逐条列出结果、可一键**撤销**；找不到的 uid / 锚点会**安全跳过并说明原因**，绝不半途写入。锚点匹配对细小差异很皮实（v1.19.2 起）：跨中文破折号（——）、引号风格不同（「」/『』/“”/"）、顿号↔逗号等标点小差异都能命中；仍未命中时，提示会建议改用「起始 || 结尾」两端锚点再试。正文**原样保存、不做宏替换**（`{{user}}` 等保持原样，不会把名字写死进书）。新建条目默认开「非递归」。

> 整本注入 token 可能较大，条目多时用条目选择器只挑几条即可。

## 🧭 剧情参谋模式（Story Advisor）⚠ 实验性

和神谕一起**构思剧情接下来怎么走**，并可一键让主聊天**被悄悄引导**。神谕会按你在设置里选的**上下文深度**与**世界书**范围读取对话与设定（**剧情概要**始终读取），据此找沉睡的伏笔、未兑现的线索、人物弧光的下一步，把可落地的走向列成**方案卡片**（`<StoryPlan>`：目标 + 起始迹象 + 契合点）。若先在普通模式聊出了感觉，切过来会有【🧭 把刚才的讨论整理成方案】按钮。回复中的 **Markdown**（加粗 / 标题 / 列表 / 表格）会正常渲染（1.18.2 起；表格 1.18.4 起），原始 `<StoryPlan>` 块以等宽小块原样展示、采纳卡片照旧。

在卡片上选**强度**（**只铺垫** / **自然推进** / **尽快引爆**）→【开始引导】，方案就作为一条幕后指令注入主聊天（ST 的 `setExtensionPrompt`，深度可调）。之后**正常 RP 即可**——主线会逐步把剧情推向该方向，且**用户行动永远优先**（你偏离时它跟随）。采用后顶部出现**方案条**（关掉窗口会变成可拖动的「🧭 引导中」悬浮标签），可随时切强度、查看注入原文、或【完成】/【放弃】。方案存在**当前聊天**里，刷新 / 切换聊天都不丢、绝不串台。

**✏️ 编辑注入内容（1.48 起）。** 方案条上的 **✏️**（预览收着时它也在）可以把注入主聊天的那段幕后指令**整份改写**——想补的细节、想禁的写法，直接写进去、点【保存】立刻生效（刷新页面也还在）。其中「**节奏：**」那一行**保持原样**时，上方三个强度档**照常可切**（只替换那一行，你写的其它内容一字不动）；一旦你**改动或删掉**那一行，就当作「节奏也自己定了」，强度档随即**置灰**（说明行会写明原因）。想找回自动生成的文本，点编辑器里的【**恢复默认**】（当前档位保留）。编辑期间强度档也暂时置灰——换档会重画方案条，把还没保存的字冲掉。自定义**随本次方案生灭**：【完成】/【放弃】/ 换一个方案都会清掉。（长线弧线**不提供**这个按钮——弧线的每拍指令由后台现编。）

**故事弧线（长线引导）⚠ 实验性。** 把单步方案升级成**多拍长线**：先定一条**贯穿线**（整条弧要讲的事），之后一拍接一拍走，每次过渡由一次后台调用现编下一拍注入主聊天，直到贯穿线**真正收束**才结束。新建时填表选**模式**（**透明** = 你看得到每拍指令；**盲盒** = 只看到给玩家的目标，幕后意图藏在剧透模糊后）、贯穿线、路标、篇幅、**难度**（平和 / 常规 / 凛冽，越高赌注越大，但「退出」永远在不可逆转折之前可达）、红线。任何时候都能【退出】、主聊天即刻复原。

> ⚠ 弧线比单步方案更吃模型与 token（每拍都通读整段历史 + 世界书），建议配**较强的模型**（DeepSeek / Gemini Pro / Opus）；流式、超时取消、📡 实时输出都已内置。

## ✨ 校正模式（Reply Fixer）

专门「修」**最新一条 AI 回复**：清掉 AI 八股套话、机械对白、过度精确的「数学论文腔」、把魔法写成理科、拖沓流水账，也能执行你定的角色知识边界 / 剧情护栏。**改动一律作为新的 swipe（重摇）应用**——原回复永远在「向左划一下」的地方；回复里的 `<UpdateVariable>` 区块会原样接回，**绝不弄坏 MVU 数值或状态栏**。

「校正设置」面板顶部有个下拉，切换**手动 / 自动**两套用法：

- **🖐 手动** —— 直接在输入框**用人话说要改哪里**（「这段对话写口语点」「把这句删掉」）。只动最新这条、只改你点名处，其余不动——回复里的状态栏 / 面板 / 图生标记等**结构块也默认原样保留**（除非你点名要改它里面的内容）。**默认精简上下文**：只发这条回复 + 角色卡，不带前文 / 世界书 / 概要（弱模型高上下文下易认错要改的楼层，需要时在面板里再逐项勾开）。改完先给一张**校正稿卡片**，满意再点 **[应用]**（这才变成 swipe）。
- **🤖 自动** —— **勾选长期想清理的目标**（5 个开关：AI 八股 / 套话、对话机械、过度精确、**魔法被写成理科**（仅奇幻，默认关）、描写拖沓 / 流水账——其余四项默认开），选**强度**（轻校默认 / 精校更彻底 + 按模型选侧重），可再填**角色知识边界 / 剧情护栏**约束、设**排除区**（保留 = 强制原样保留自动没认出的块；丢弃 = 直接删掉，如 `<thinking>`）——这些和作用域 / 套餐都收在**「进阶设置」**折叠里。两种触发：点 **[按目标校正最新回复]** 跑一次（**流式直播**校正稿，停止键可随时中断），或勾 **[自动校正每条新回复]** 常驻后台跑（✨ 图标染金为提示）。

> 💰 自动模式默认只发回复正文 + 目标，并带**禁词预筛 + 字数下限**——回复本就干净 / 太短时**根本不发起调用**，不会每条烧 token。

自动改完会**应用为新 swipe** 并在侧聊留记录，带 **[用原文]**（划回原稿）/ **[看改动]**（逐字对比）。配置**按当前聊天保存**，还能存成具名**套餐**（如「硬核西幻」）一键复用。

> 🎯 **自动识别（v1.17.16 起，v1.18.3 加「检测收据」）**：自动模式只改**正文**——正文在哪个包裹标签里（`<content>`、`<gametxt>`、`<正文>`…）会**自动识别并按聊天记住**，正文内外的状态栏 / 选项 / 面板 / 图生指令等结构块**不送模型、原样原位保留**；认不准的卡它会**问你一次**（面板「✋ 需要确认」点一下）。**常见格式开箱即用**；格式特别的卡打开「进阶设置」看**检测收据**（本条实际识别到的块），认漏的点一下固定进保留区——也欢迎把那条回复原文在 **Discord 私信 @Prince**，会加进测试集修复。**判定预览行**随时告诉你「这条回复会被怎么处理」；你**手填**的标签不会被自动覆盖；配乱了点「**恢复推荐设置**」一键还原（会一并清掉已确认的正文形态）。

## 🎭 角色工坊模式（Character Builder）

跟神谕聊几句就能把一个角色从零打磨成完整设定——写进世界书里的一条 **NPC** 条目。和其它模式一样**不碰主聊天**；唯一的输出只在最后一步 **写入** 时才真正落盘，随时可**撤销**。

> 🚧 **Persona（用户角色）目标暂时下架（v1.23.5）**：用户信息的写法正在整个重做——角色卡是给 AI「演」的，用户信息是给 AI「读」的，不该用同一套模板。重做完成后会以专门针对用户角色的新形态回归；在那之前工坊只写 NPC 条目。

- **目标下拉**：目前只有 **NPC 世界书条目**（Persona 目标重做中，暂时下架）。是全新 NPC、改已有条目、还是剧情里出现过但还没写进书里的角色，这些更细的选择由**访谈师**在聊天里问你确认。
- **草稿包含**：一排可勾选的章节 chip，决定这次要写哪些内容——**勾选＝送进锻造工序，没勾的章节会从锻造提示词里物理删除**（访谈师不问、锻造不写、也不会「顺手」多写，所见即所得）。默认开：基本信息 / 外貌特征 / 背景经历 / 人际关系 / 性格画像 / 说话方式 / 目标动机 / 深层人格 / 防误读提示；默认关：弱点缺陷 / 能力技能（排在普通章节末尾），以及最后带**虚线边**的**进阶三件**：多副面孔 / 言行反差 / 点睛比喻（勾选前有一行「简单 / 喜剧调剂角色留空」提示）。桌面端鼠标停在 chip 上看说明；手机上点「草稿包含」旁的 **「？」** 看完整图例（顶部有进阶三件的取舍指引）。
- **上下文**：世界书多选 + 条目选择器（同世界书模式的机制）——**角色类条目通常是绿灯**（关键词触发），要编辑或参考某个已有角色务必**先勾上它所在的那本书**，不然锻造读不到；上下文深度（数字 + 「全部」勾选）往上调到能看见该角色出场的位置为止（长聊天开「全部」比较吃 token）；「带上 📜 剧情概要」；「带上状态栏数据」（世界里有数值化角色设定时有用）；「**关键词触发世界书**」（默认关，v1.31.0）——开了会额外跑一次 ST 关键词扫描，把主聊天 / 访谈侧聊里**提到**的设定条目（蓝灯 + 命中绿灯）作为参考补充喂给访谈师和锻造，**已勾选的条目不会重复投喂**，你勾的书 / 条目仍是唯一权威。
- **锻造回复上限**：锻造调用的 max_tokens，留空 = 自动（下限 16384，v1.29.0 起；v1.23.0 起曾 12288，更早 8192 时全章节的重型锻造约半数会被「思考+成稿」截断）。还嫌不够时可再调高——但超过服务商的单次输出上限会被直接拒绝，报错就调回来。另注：巨型世界书吃的是**输入**上下文（受模型上下文窗口限制），要精简靠条目选择器和上下文深度，这个旋钮管不到输入侧。
- **用自定义预设**：勾选后**访谈对话**走你在设置面板策展的酒馆预设（文本块保留、RP 标记去除）；**锻造调用不受影响**，始终使用内置锻造工序。
- **锻造后自动精简**（v1.30.0，默认关）：锻造成功后自动跑一遍「✂️ 精简」。只在 NPC 草稿、且原稿明显冗长（长句密集）时才触发；守卫不过 = 原稿原样保留，一行注记说明原因。强输出模型（如 Claude）建议开。
- **台词丰满**（v1.34.0，默认关）：锻造时把台词写成**当面说出口的完整人话**——保留角色个性与说话习惯，话少的角色照旧话少、但开口的句子完整不碎。嫌锻造稿台词干就开它；个性、条数、卡片结构不受影响。
- **深度精简恒串行·流式**：「✂️✂️ 深度精简」的 3 份分节 + 手术单**一份接一份**地跑（不再有并行/串行开关），任何时刻只有一个请求在天上——不撞公益站的并发限流，流式的持续字节流也扛得住会掐长请求的代理。进度实时铺在气泡里。v1.35.4 起分节与手术单的内部思考同样加了**一遍成稿纪律**（台词保护原样焊死）：爱反复推敲的强推理模型不再把分节想到超时截断——此前偶发的「精简未采纳：第 N 份分节没有有效围栏」正是这么来的，实测该故障从 1/3 概率降到 0/3，整轮耗时约减半。
- **✂️ 精简全稿 / ✂️✂️ 深度精简 / 原稿切换**（v1.30.0，草稿卡按钮）：把冗长的锻造稿拆短句、删跨节重复——台词、章节结构、状态行、画面与衍生的实体一律原样保留，整套守卫兜底，任何一道不过就自动回落原稿。成功后卡上出现**「原稿 ⇄ 精简稿」**切换钮（●标当前侧），**写入和修订都以当前显示的版本为准**；切回**原稿**侧时两个精简按钮仍在——想换一档重跑随时可以（重跑覆盖旧精简稿）；对精简稿提修订后，两个版本收敛为修订后那一份（切换钮收起）。

> 💡 chip 就是这份设定的「体量旋钮」——全勾默认打出来的是**主角级**完整设定（约 2000 字）。**排在最后的进阶三件（多副面孔 / 言行反差 / 点睛比喻）默认关**，勾给**有内在层次**的角色；喜剧调剂 / 纯功能 / 简单直给的角色**留空就好**。是否需要由**你**决定——**勾了＝一定做，不勾＝一定不做**（不再由模型自己判断适不适合）；给一个简单角色勾上进阶件，锻造会照做、硬造出它本没有的复杂。打个酱油的次要 NPC，连**深层人格**也可以关掉，一盘清爽的调色盘就够了。

描述完你想要的角色，访谈师只会追问**答得上来的客观信息**（外貌、年龄、性别、身份、性格梗概……），一次 2-3 个问题，你的描述 / 已勾的世界书 / 聊天记录里写明的东西不会重复问。信息够了会出一张**〈角色简报〉**摘要卡，点 **「🔨 生成」** 才真正开始锻造——之前不会有任何调用。

> 💰 锻造是**一次较重的调用**：会读入你配置的全部上下文，先在世界书里找有没有**角色生成规则**（命名规矩、种族限制、数值模板……），找到就当**硬性约束**照办；打磨过程在内部完成，你只会看到成品，粗略估算输出量是普通回复的 2-3 倍。这次调用只在你点「生成」时才发生，绝不自动触发。v1.35.3 起锻造的内部思考加了**一遍成稿纪律**——爱反复推敲的强推理模型（如 Claude Opus 一类）不再把五道工序整个重想一遍，锻造明显更快更省（实测该类模型耗时/输出砍半），成品质量与结构不变。

> ⏳ 🔨 锻造与 ✂️✂️ 深度精简都是**后台保活**调用（锻造 v1.35.2 起、深度精简 v1.36.0 起）：发出后切到别的模式**不会中断**它们——后台照常跑，回到工坊房间时流式气泡自动接上，完成后成稿按原始房间落盘归位（人不在场不弹打扰通知，回房自见）。生成期间发送键显示为 ⏹ 停止键，点它仍会中止；**切换聊天**或清空该房间的侧聊记录也会中止（结果属于旧聊天，不会写进新聊天）。

草稿出现在**窗口顶部「角色工坊」面板底部的常驻卡片**里——锻造完成会自动把收起的面板展开（v1.19.2 起；之后想再看，点「角色工坊」标题展开即可）。刷新页面、切走再回来都还在，按聊天各自保存。锻造稿收尾的小滑手能自动救回（v1.19.2 起）：漏了闭合标签、闭合多打了几个 `>` 都不再白丢一稿；思考区块忘了闭合也不会把成稿吞成「(空回复)」。想改就直接说要改哪里——神谕会先**用普通文字引用原句、给出替换建议**征求你确认；全部确认、你说**「改完了」**之后才输出**唯一一个**补丁、**一次性逐字精确**地套进草稿，且**只含你确认过的修改**（不会重新整篇改写，也不会夹带没让它改的地方）。补丁锚定和世界书补丁同样皮实——跨「——」、引号风格不同、标点小差异都能命中。满意就点 **「写入」**；**「🔨 重新锻造」**整份推倒重来；**「放弃草稿」**直接清空。

写入会在目标世界书里**新建一条**（或**改写**你选定的已有条目），并自动配 3-5 个触发关键词。（Persona 写入——完善当前角色 / 另存新角色——随 Persona 目标一同暂时下架，重做后回归。）

> ⚠ **撤销只在这次会话里有效**——刷新页面、切换聊天、修订生效后（改稿套进草稿）、或点「重新锻造」都会让上一次写入的撤销失效。写入后尽早核对，不对就趁早撤销。

## 侧聊历史与运行概要

- **侧聊历史按聊天持久化**：每个聊天各存自己的一份，关窗 / 刷新 / 切走再回来都不丢；只有点标题栏 🗑 **清空**才清掉当前聊天的。
- **每模式独立侧聊房间（1.28.0）**：普通聊天 / 诊断 / 世界书 / 参谋 / 校正 五个模式**各存各的一份侧聊历史**，切模式即换成该模式自己的记录——普通聊天里的闲聊不会混进诊断，反之亦然；每份都按聊天持久化、跨刷新存活，非普通模式的记录顶部有一行「本模式独立保存」提示。进**参谋**时若普通聊天已有讨论，会出现一个一键「**导入普通聊天的讨论并整理成方案**」按钮，把刚才的闲聊搬进参谋房再帮你整理成方案卡（参谋始终会通读真正的主聊天剧情，这个按钮只是把侧聊里的讨论一并带上）。
- **运行概要（📜，在「⋯ 更多」菜单）**：把剧情关键背景写成一段概要，存进当前聊天，之后在普通聊天与参谋模式下插在最近对话**正前方**喂给神谕——长 RP 里给它补全局背景。诊断模式不带；世界书模式勾「同时带上最近剧情对话」时一并带上（1.46.0 起）。

## 对话操作

鼠标移到任意消息上，气泡角落出现小按钮：**你的消息**可 ✎ 编辑（保存并重新生成）/ 🗑 删除；**神谕的回复**可 ↻ 重新生成 / 🗑 删除。删除前会弹确认框（1.22 起；删除提问时若其后紧跟神谕回复会提示一并删除；出错气泡直接删、不打扰）。**发送失败时**（如共用 key 被 `429` 挡回），出错气泡上会显示常驻的 **↻ 重试**，点一下即可重发、不必重打（手机尤其方便）。Enter 发送、Shift+Enter 换行。

## 进阶选项

- **用补全预设作为系统提示词来源。** 除了直接写提示词，还可让神谕**沿用某个 Chat Completion 预设的结构**：首次选中会弹出**挑选清单**，逐块决定去留并可拖动排序（故事 / 世界 / 人格类默认保留，思维链 / 字数 / 文风等输出块默认去掉），保存后**冻结成快照**（之后改原预设不影响这份，点 [↺ 重新挑选] 才更新）。发送时**忠实复刻**主聊天的提示词结构（各插槽就地填入、保留每块的角色、宏实时解析且 `setvar` 会自愈不污染主聊天）。**选用预设时人格与下方系统提示词文本框都会停用。** 开了「应用剧情正则」时神谕会像主聊天一样渲染自己的回复（状态栏美化等正常显示）。
- **说话人格。** 普通 / 泉こなた / 贝阿特丽丝 / 胡蝶忍 给神谕套一层说话腔调（选「普通」= 不叠加）。**选预设时默认关**以免冲突。参谋 / 世界书模式下人格只改语气，不影响方案区块格式或写入条目的正文。诊断模式不生效。
- **自定义人格（1.39.0）。** 下拉旁的 ✎ 打开编辑器：起个名字、写一段「这个人格怎么说话」（性格、态度、口头禅——职责规则如「分析必须准确、知无不言」由神谕自带，不用写），保存后出现在下拉的「── 自定义 ──」组里，与内置人格一样在普通 / 参谋 / 世界书模式生效（诊断模式同样不生效）。只有一个粗略点子？点「✨ AI 帮我完善」让当前连接的模型把几个词扩写成完整描述（附示例对话），不满意可「↩ 撤销」。最多 20 个。
- **自定义各模式提示词。** 设置里有个模式下拉，可查看 / 改写**诊断**、**世界书**与**剧情参谋**（单步方案，1.17.7 起）模式的内置提示词（未改时随更新自动改进，改了就冻结，[↺ 重置为默认] 还原）。弧线编译等长线提示词不开放。
- **读取其它扩展的后台世界。** 勾「附带『世界引擎』后台世界状态」（默认开）后，神谕会在普通聊天与参谋模式读入**世界引擎 / World Engine** 维护的幕后世界状态（正在酝酿的事件、势力动向……），于是你能问「外面正在发生什么」。目前仅适配世界引擎；未识别到相关扩展时无开销。
- **读取柏宝书的历史剧情摘要（1.33.0，1.46.0 扩展触达）。** 如果你在用**柏宝书（ST-BaiBai-Book）**记忆扩展：它会把窗口外的旧楼层隐藏、只给主模型留摘要——而神谕默认不读隐藏楼层，等于「只看得见最近几十楼」。勾「附带『柏宝书』历史剧情摘要」（默认关）后，神谕在普通聊天与参谋模式会把柏宝书的**被隐藏旧楼摘要**（带「昨天 / 三天前」相对时间标注）插在对话记录之前——问三百楼前的旧事也答得上来；**校正 / 工坊**勾「带上剧情概要」时也一并附带；**世界书模式**勾「同时带上最近剧情对话」时随之附带（此时运行概要也会一并带上）；**已注册的插件模式 / 二创**（如大纲版）经接口读取故事记录时也自动附带。与所有连接方式、预设路径都兼容。诊断模式有意不接（概要与摘要都不进诊断——审计以 stat_data 为准）。注意保持「读取隐藏楼层」关闭（否则原文与摘要重复喂两遍）；未安装柏宝书时勾了也无开销。
- **读取小白X 的剧情总结记忆（1.50.0）。** 如果你在用 **LittleWhiteBox（小白X）** 的「剧情总结」：它把早期剧情压成记忆、只在主聊天生成时喂给主模型——神谕平时读不到。勾「附带『小白X』的剧情总结」（默认关）后，神谕会在主聊天生成时悄悄记下那份总结，之后在普通 / 参谋 / 世界书 / 校正 / 工坊里当背景一起看，于是问早期剧情也答得上来。重开酒馆也记得住（存在本聊天里）；刚装上立刻问、还没生成过时，也会现取一份垫上。诊断模式有意不接；未安装 / 未开启小白X 时勾了也无开销。
- **机制块 / 思维链自动隐藏。** 普通 / 参谋模式会自动从显示和历史里剥掉回复内嵌的 `<UpdateVariable>` 增量块与泄漏的 `<think>` 思维链（诊断模式保留——读它们是其本职）。

## 界面

- 空对话时窗口中央有**示例问题 chip**，点一下即填入输入框（每种模式各一组）。
- 全键盘可用 + 读屏支持，尊重系统「减少动态效果」；移动端触摸目标更大。
- **各模式的配置栏**（诊断 / 世界书 / 校正 / 工坊 / **参谋**）都可整条折叠（手机默认折叠、限高半屏）；破坏性操作弹 ST 主题化的确认框。（参谋栏 1.20 起也能折。）
- 消息操作按钮（复制 / 重生 / 编辑 / 删除）默认排在**气泡底部**、鼠标悬停显影（1.20 起）；切换模式时会**自动收起设置面板**。
- **切换模式的中断确认（1.36.0）**：有回复正在生成时点别的模式按钮 / ⋯ 菜单「普通聊天」/ 工坊打造目标下拉，会先弹确认框——切换会**中止并丢弃**这条未完成的回复，确定才切、取消留在原地。锻造与深度精简是后台保活调用、切模式不中断，所以不会弹这个框。
- 「界面」设置里的开关（1.20 起）：把 ⋯ 菜单的工具按钮**移到标题栏**（省一次点击，默认关、⋯ 菜单仍在；1.37.1 起窗口装不下时按钮**自动换行**到第二行——之前在手机上会把右上角 ✕ 挤出窗外、按不到）。（旧「开发者·控制台打印提示词」开关已于 1.37.2 移除——它是早年二创调试的遗留，与 ⋯ 菜单里的「调试提示词」面板完全重复。）
- **点击窗外自动收起（1.48 起，默认关）**：「界面」设置里勾上后，点酒馆页面的其它地方（正文、输入框等）就把神谕窗**收起**。点窗内、方案浮条、📡 实时输出、酒馆的弹窗 / 提示条、魔杖菜单、🌙 与 ✂️ 快捷按钮都**不算窗外**；**划词选字、滚屏也不会**误触发（选段校正的划选流程照旧可用）。收起只是隐藏——模式、侧聊、方案统统保留，从魔杖或 🌙 再点开一切如旧。1.48.1 修复了**窗口配色选「深色 / 浅色」时点哪都不收**的问题；另外若浏览器装了 **uBlock Origin** 等拦截扩展且勾了也没反应，请为酒馆地址关闭拦截（实测它会拦掉这类点击监听）。
- 退出子模式会回到**进来之前**的那个模式，而不是一律掉回普通聊天。
- **移动 / 调整大小**：拖标题栏移动、拖右下角握把缩放（鼠标和触屏都支持）；位置与尺寸都记住，并自动限制在屏幕内。
- **🖥 全屏阅读（1.51.0）**：点标题栏的全屏图标（在 ✕ 左侧），窗口**铺满屏幕**；再点一次或按 **Esc** 退出，回到悬浮窗口（位置 / 大小不变）。适合手机上长对话阅读。纯显示切换，刷新页面回到悬浮窗口。

## 扩展开发接口（Hook API · 面向二创 / 插件作者）

想给故事神谕**加一个自己的模式**、又不想每次它更新就重抄一份代码？从 **1.21.0** 起，故事神谕在页面上挂出一个**版本化的稳定接口** `window.StoryOracleAPI`（外加 `story-oracle-ready` 事件）。你的插件**只装一个自己的文件**、监听这个接口即可——不必打包故事神谕，主体更新（只要主版本号不变）也不会打断你。

- **首选 `registerMode(spec)`**：声明一个模式（图标 / 标题 / 输入框占位 / 设置栏 / `onSend`）——DOM、渲染、模型调用全由主体负责，你只写「这个模式该怎么想」。
- 还有：`addMessageAction()`（每条回复挂按钮）、`updateReply()`（改写并持久化一条回复）、`api.context.*`（角色卡 / 世界书 / 对话记录只读构建器，与内置模式同源）、逃生阀 `api.run()` + `api.appendReply()`（onSend 覆盖不到时才用）。用 `api.isCompatible(1)` 做版本闸；回复的原始模型输出存在 `.so-content` 的 `data-so-raw` 上，便于读自定义标签。
- **完全开放逃生阀 `api.unsafe.eval(code)`**（1.22 起）：在故事神谕**模块作用域内**求值——可直读 / 改写内部任意顶层函数与状态（含日后新增的），插件侧可完全自助、无需逐项对接。⚠ **非正式接口**：不入版本契约、无任何兼容承诺，主体更新后失效 / 变样由插件侧自行适配；首次调用会在控制台打一条提示，排查异常时请先停用相关插件再复测。日常仍**首选上面的正式接口**。
- **可直接照抄的范例插件**：`data/default-user/extensions/so-example-plugin/`（不打包故事神谕，仅监听接口）。完整接口文档见仓库 `docs/superpowers/specs/2026-07-05-story-oracle-hook-api-design.md`。
